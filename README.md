# Real vs AI Image Classifier

Binary classifier separating real photographs from AI-generated images. Random Forest and XGBoost on 15k+ images, about 92% test accuracy.

`real_vs_ai_classifier.py` is a Colab export (expects `test.zip` of images at `/content`). Update the paths to run elsewhere.

Related: [ai-image-generator-classification](../ai-image-generator-classification) attributes an image to a specific generator.
